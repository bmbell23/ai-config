What you need to do
Before: Save open work in /home, and don't start long jobs or CI runs that write to fs-01 after 5:00 PM MT.
During: Shells and editors on a dev VM may freeze when they touch /home. Wait it out; don't reboot your VM.
After: Everything should resume by itself. If something still hangs 15 minutes after the all-clear, reply to this email.
Why
fs-01 runs an old kernel that fragments its memory over time. Once memory is fragmented, fs-01 can't set up new InfiniBand connections to its storage. Storage paths that drop can't reconnect, so we slowly lose redundancy. A reboot resets the memory layout. It took 31 days to reach this state last time; this time it took 13.
What's next
The lasting fix is moving off fs-01. That plan is in OPS-1400 and gets reviewed Thursday, Nov 19. Until then, we'll announce any further reboots the same way.
